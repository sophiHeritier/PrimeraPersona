Este proyecto es un prototipo técnico en primera persona (FPS) desarrollado en 3D, enfocado en validar y refinara las mecánicas base de movimiento, 
cámara y control de disparo dentro de un entorno preliminar. 
El estado actual de la demo sirve como prueba de concepto funcional, por lo que incluye escenarios y assets temporales que serán reemplazados progresivamente.
A futuro, se esperan importantes mejoras.
